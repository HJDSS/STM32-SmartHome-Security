# 单芯片 STM32F103RCT6 智能安防系统 · 硬件调试 Checklist

> **依据**：`代码/User/board_config.h`；与《单芯片STM32F103RCT6智能安防工程重构规范》《工程真实硬件连接表》对照使用。  
> **说明**：勾选框供实机调试时逐项打勾。**SCCB 为 PD2/PB7**，与 OV **OE(PB6)** 无同脚复用；键盘行 **X1~X4=PC0/PC1/PC2/PC3**（**X4 勿用 PC10**，该脚为蜂鸣器，见 **`BOARD_BEEP_ACTIVE_HIGH`**）；列 **Y1/Y2=PC11/PC12**；Y3/Y4 **默认 PB1/PB2**（固件 **`EN_OV7670_LOCAL=1`**）；无摄像头调试时改宏为 **0** 且列改 **PA5/PA6**；**PA13/PA14 仅 SWD**；**蜂鸣器为 PC10**（见《硬件连接方案》§3.7、`BOARD_BEEP_ACTIVE_HIGH`）。

## 一、上电前检查（必做）

| 序号 | 检查项 | 要点 | 通过 |
|------|--------|------|:----:|
| 1 | 电源极性 / 短路 | 万用表蜂鸣档：3.3V 与 GND 无短路；稳压输出 ≈3.3V | [ ] |
| 2 | 共地 | 外设模块 GND 与 MCU 板 GND 可靠共地 | [ ] |
| 3 | OLED（软件 I2C） | **PB8** = SCL，**PB9** = SDA；多数模块为 3.3V 逻辑 | [ ] |
| 4 | ESP8266 串口 | **PB10** = USART3_TX → 模块 RX；**PB11** = USART3_RX ← 模块 TX；**3.3V TTL**（与 **PA0~PA7** 摄像头并口无共脚） | [ ] |
| 5 | ESP8266 EN | **PC9** 接模块 EN/CH_PD（以 `board_config.h` 为准） | [ ] |
| 6 | AS608 指纹 | **PA9/PA10** = USART1；波特率与固件一致（见下节） | [ ] |
| 7 | PC10 蜂鸣器 | **PC10**；仍无声时试改 **`BOARD_BEEP_ACTIVE_HIGH`** 为 1；键盘 **X4=PC3**；勿与 **PB10**（USART3 TX）混淆 | [ ] |

## 六、快速排障索引

| 现象 | 建议先查 |
|------|----------|
| 下载失败 | SWD 线序、复位脚、BOOT0、驱动 |
| 串口无打印 | USART1 波特率 57600、USB-TTL 地线、是否被 AS608 占用 TX/RX |
| WiFi 不通 | PB10/11、3.3V、EN(PC9)、波特率 115200、天线与供电；勿占用 **PA0~PA7** 作串口 |
| OLED 不亮 | PB8/9、上拉、I2C 地址、3.3V |
| 键盘失灵 | 四行是否 **PC0/1/2/3**（**R4→PC3**）、Y1/Y2 **PC11/12**、Y3/Y4 **PB1/2**（默认）或关 OV 时 PA5/6；是否误接 **PC10**（蜂鸣器）；AFIO/SWJ、行列是否短路 |
| 摄像头异常 | SCCB ID、分时复用、与 SD/OV 脚冲突 |
