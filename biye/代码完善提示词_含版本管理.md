## 1) 项目背景与总目标（最新版）

- 论文主题：家用安防与智能家居联动系统（STM32F103RCT6）
- 工程形态：以 `board_config.h` 为硬件配置基线，支持裸机调试路径，并保留 FreeRTOS 论文描述对应实现
- 目标：让代码与论文中的硬件接口、功能逻辑、测试指标、异常处理策略保持一致，形成可编译、可联调、可验收版本
- 关键新增要求：摄像头抓拍时**必须本地落盘一份到 SD 卡**（云端查看与本地留存双通道）

## 2) 必须遵循的全局约束

1. **不改变核心硬件选型与引脚事实**（以 `biye/代码/User/board_config.h` 为准）
2. **不删除现有可用功能**，仅做补全、修复、对齐
3. **所有改动必须可追踪**：按功能拆分提交，提交信息清晰，禁止一次性大杂烩提交
4. **代码风格统一**：沿用当前工程风格（标准外设库/HAL兼容方式、命名风格、注释风格）
5. **优先保证稳定性**：先修编译与关键链路，再做增强

## 3) 与论文和历史记录对齐的功能清单（按优先级）

### P0（必须完成）

1. **ESP-01S 通信链路对齐**
   - USART3: PB10/PB11
   - EN/CH_PD: PC9
   - 默认波特率与联网参数走 `board_config.h` 宏
   - 启动流程：AT连通性检查 -> 入网 -> MQTT会话
   - 异常：重连、超时、状态回执

2. **SD 卡模块对齐**
   - SPI2: PB13/PB14/PB15，CS=PB12
   - FatFs 挂载流程与容错参数按 `board_config.h`
   - 仅在 `EN_FATFS_SD` 启用时生效
   - 挂载成功后再开放 BMP/日志写入，避免未就绪访问
   - 抓拍触发时执行：`OV7670/FIFO取帧 -> BMP编码 -> SD本地落盘`
   - 网络在线：上报图片地址/抓拍时间；网络离线：本地缓存待上报记录，重连后补传
   - 写卡失败不得阻塞本地安防告警动作（降级但不中断安全链路）

3. **DHT 与 MQ-2 对齐**
   - DHT 引脚 PC5，按 `BOARD_DHT_SENSOR_TYPE` 区分 DHT11/DHT22
   - MQ-2 ADC: PB0 / ADC_Channel_8
   - 采样、滤波、阈值判定逻辑与论文一致
   - 处理传感器失效/超时/悬空边界
   - 传感器离线检测与恢复：
     - DHT：连续超时/校验失败置离线，指数退避重试，连续成功自动恢复
     - MQ-2：长时间恒定或越界置异常，异常期间禁止触发应急关阀误动作
     - PIR：非布防高频触发进入抑制窗口并记日志

4. **执行器链路对齐**
   - 门锁 PC6，燃气阀 PC7，蜂鸣器 PC10
   - 蜂鸣器触发极性由 `BOARD_BEEP_ACTIVE_HIGH` 控制
   - 异常状态进入安全态（尤其复位后）
   - 看门狗复位后：执行器默认安全态（关阀、门锁默认态、蜂鸣器关闭）

### P1（建议完成）

   - 重连幂等：下行命令基于 `cmdId+ts` 去重，避免重复执行

6. **日志与诊断**

7. **参数集中化**
