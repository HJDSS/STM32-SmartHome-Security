# 使用说明书（单芯片 STM32F103 智能安防与智能家居系统）

**适用对象**

- **唯一固件工程**：`biye\代码\`（Keil：`biye\代码\User\程序.uvprojx`）
- **目标芯片**：与工程选项一致，当前为 **STM32F103RC**（256KB Flash，与 **STM32F103RCT6** 同系列 LQFP64；具体以 Keil **Device** 为准）

**硬件总览**：请阅读 **`biye\硬件\硬件连接方案.md`**（**单芯片**：全外设接线、**§2 杜邦线分束**、USART 分工、电源与共地）及 **`biye\硬件\单芯片STM32F103RCT6智能安防系统_硬件调试Checklist.md`**（上电与分步调试）。**引脚以 `biye\代码\User\board_config.h` 为权威**；可选对照 **`biye\硬件\主机核心板排针接线表.md`**（多为 C8 双列排针丝印，64 脚板请以实际引出为准）。

**版本说明（与当前默认源码一致）**：**无主从串口、无从机工程**。**ESP8266** 使用 **USART3（PB10→模块 RX，PB11←模块 TX），115200**，**EN/CH_PD=PC9**（与 **PA0~PA7** 摄像头并口无共脚）；初始化函数名为 **`USART2_Init_Config(115200)`**（内联初始化 USART3，历史命名）。**USART1** 为 **AS608** 与 **`printf`/JSON 调试**（`main.c` 中 **`uart1_Init(57600)`**）。修改波特率后，USART1 上所有共用设备（指纹、USB 转串口监听）须一致。

## 0. 首次上电前检查清单

| 序号 | 检查项 |
|------|--------|
| 1 | 各模块与 MCU **GND 共地**；独立 USB 供电时 USB-TTL 的 GND 务必接板 GND |
| 2 | **勿**将 **ESP8266** 接到 **USART1**（与指纹 / `printf` 冲突）；ESP8266 接 **USART3：PB10→模块 RX，PB11←模块 TX**；**勿**占用 **PA0~PA7** 作串口（OV 并口） |
| 3 | **ESP8266 EN/CH_PD** 按 **`board_config.h`** 接 **PC9** |
| 4 | SD：**CS=PB12**，**PB13–PB15** 为 SPI2；FatFs 盘符 **`0:`** |
| 5 | OLED：**PB8=SCL、PB9=SDA**（软件 I2C）；键盘列 **Y3/Y4**：固件**默认** `EN_OV7670_LOCAL=1` 时为 **PB1/PB2**（与 **PA0～PA7** 无共脚）；仅当改为 **`0`**（不接本地摄像头）时用 **PA5/PA6** |
| 6 | **SWD** 固定 **PA13/PA14**（关 JTAG、保留 SWD）；**勿**将键盘或其它 GPIO 接到这两脚 |
| 7 | 当前默认 **`EN_OV7670_LOCAL=1`**：须接满 **OV7670+FIFO+SD**，键盘 **Y3/Y4→PB1/PB2**；若改为 **`0`** 调试无摄像头系统，可改接 **PA5/PA6** 并关宏（详见《硬件连接方案》§2、§6） |

## 1. 工程结构说明（单芯片）

### 1.1 目录与关键文件 — `biye\代码\`

| 目录/文件 | 说明 |
|-----------|------|
| `User\main.c` | 系统初始化、FreeRTOS 任务、门禁与联动逻辑；**燃气阀** 见 **`board_config.h`（PC7）** 与 **`Emergency_IO_Init`** |
| `User\FreeRTOSConfig.h` | FreeRTOS 配置 |
| `User\board_config.h` | **单芯片**引脚与功能开关（**保留 SWD**、无通风/空调继电器）；OLED **PB8/PB9**、USART1/3、OV、SD、键盘、MQ-2 **PB0**、ESP8266 **USART3 PB10/11 + EN=PC9** 等 |
| `User\oled_remote.c` | 本地 OLED 编译入口（内部复用 `Driver\oled.c`） |
| `User\capture_task.c/.h` | 抓拍 **事件队列**：`Capture_Request()` → `Task_Capture` |
| `User\Capture.c/.h` | **本机** OV7670+FIFO 采集、写 **SD** BMP（**默认开启**；键盘 **Y3/Y4** 为 **PB1/PB2**，见 `EN_OV7670_LOCAL`） |
| `User\linkage.c/.h` | 智能联动；照明 **PC8**；无空调/通风继电器 |
| `User\secure_store.c/.h`、`aes128.c/.h` | 安全存储与加密 |
| `User\esp8266_tls.c/.h` | **ESP8266 AT（物理 USART3，驱动符号 UART2_*/`Uart2_Buf`）**；OneNET **TCP + MQTT 3.1.1** 等（宏见文件顶部）；`esp8266_tls.h` 含 **`MQTT_TLS_ENABLE`** 等 |
| `User\esp8266_onenet_mqtt.c/.h` | 可选：**AT+MQTT** 路径（**`ONENET_MQTT_ENABLE`** 等，与 `Task_Wifi_MQTT` 分支相关） |
| `User\syslog.c/.h` | Flash 循环日志 |
| `User\sd_capacity.c/.h` | SD 容量统计：可能为占位实现（`sd.status` 长期 `unmounted`、容量为 0），启用 FatFs `f_getfree` 后可恢复真实值 |
| `Driver\` | DHT11、PIR、AS608（**USART1**）、键盘、**`mq2.c`（PB0）**、SPI/SD、**`usart2.c`（初始化 USART3 供 ESP8266）**、**`usart3.c`**、OV7670+FIFO、SCCB 等 |
| `Middlewares\FatFs\`、`Middlewares\FreeRTOSV9\` | 文件系统、RTOS |

**说明**：`board_config.h` 中 **`EN_OV7670_LOCAL`** 等宏控制 OV/SD 等是否参与编译；**以 `程序.uvprojx` 中实际加入的源文件为准**。

### 1.2 引脚与模块速查（与 `board_config.h` 一致）

安装与排查时请对照 **`硬件\硬件连接方案.md`**，以下为常用摘要：

| 功能 | 引脚 | 备注 |
|------|------|------|
| PIR | **PC4** | EXTI4 |
| DHT11 | **PC5** | 单总线 |
| AS608 UART | **PA9 / PA10** | USART1，**57600**（默认） |
| AS608 **PS_Sta** | **PA8** | 状态输入 |
| MQ-2 AO | **PB0** | **ADC1_IN8**（`Driver\mq2.c`） |
| 门锁 / 蜂鸣器 | **PC6** / **PC10** | `gpio.c`：`RELAY`；蜂鸣器见 **`gpio.h`** `BEEP_SoundOn`/`Off`，极性 **`BOARD_BEEP_ACTIVE_HIGH`** |
| 燃气阀（应急关阀） | **PC7** | `Emergency_IO_Init` |
| 联动照明（`linkage`） | **PC8** | 见 `linkage.h` |
| 通风 / 空调 | — | **本版不包含** |
| 矩阵键盘 | 行 **PC0/PC1/PC2/PC3（X4）**，列 **Y1/Y2=PC11/PC12**，**Y3/Y4**：默认 **PB1/PB2**（`EN_OV7670_LOCAL=1`）；`=0` 时 **PA5/PA6** | 4×4；与 `board_config.h` 同步；**PA13/14 仅 SWD** |
| SD SPI2 | **PB12(CS)，PB13–PB15** | SPI2 |
| OLED | **PB8 / PB9** | 软件 I2C |
| ESP8266 | **PB10→RX，PB11←TX** | **USART3** **115200**；**EN→PC9** |
| USART2（PA2/PA3） | — | **本工程未初始化**；接满 OV 时 **PA2、PA3** 为 **D2、D3** |

### 1.3 三路 USART 分工（必读）

| 串口 | 引脚 | 默认波特率 | 连接对象 | 用途 |
|------|------|------------|----------|------|
| **USART1** | PA9 TX / PA10 RX | **57600** | AS608 + USB 转串口（调试） | **指纹**、`printf` **JSON**、**`CMD:`** 日志命令（**共用一路，建议分时**） |
| **USART3** | PB10 TX / PB11 RX | **115200** | ESP8266 | **AT / MQTT**；由 **`USART2_Init_Config`** 初始化；缓冲 **`Uart2_Buf`**（命名历史遗留） |
| **USART2** | PA2 / PA3（芯片默认复用） | — | **不接 ESP** | **未使能**；**PA2~PA4** 为 OV **D2~D4** 时勿改作串口 |

**注意**：**`USART3_IRQHandler`** 对接收字节 **同源写入** **`Uart2_Buf` 与 `Uart3_Buf`**（后者供 **`UART_Remote_Ctrl` / `Security_Check_Serial_Command`**）。ESP **AT 回显**与遥控解析可能叠加，异常时可从缓冲与解析条件排查。

## 2. 编译与下载说明

### 2.1 工程与芯片

1. 用 Keil 打开：`biye\代码\User\程序.uvprojx`
2. 目标芯片：**STM32F103RC**（或与板子一致之 F103 **LQFP64**），系统时钟以 `system_stm32f10x.c` 为准（常见 **72MHz**）
3. **Build** 通过后 **Download**（SWD：**PA13/PA14**）
4. 若报缺少头文件，确认 IncludePath 含：`User`、`Driver`、`Middlewares\FatFs`、FreeRTOS 等（与工程选项一致）

### 2.2 下载与上电顺序建议

- **仅需烧录本工程一次**；上电前确认 **各外设共地**。
- 当前默认 **`EN_OV7670_LOCAL=1`**：按《硬件连接方案》接满 **OV7670+FIFO+SD**，键盘 **Y3/Y4** 接 **PB1/PB2**；编译下载后先做摄像头与 SD 联调。若暂时无摄像头，将宏改为 **`0`** 且 Y3/Y4 改接 **PA5/PA6**。

### 2.3 调试注意

- 使用 **PB3/PB4**（OV WRST/RRST）等时工程已 **关闭 JTAG、仅保留 SWD**；**PA13/PA14 始终为 SWD**。

### 2.4 Keil 与 `printf` / 浮点 JSON

- **`DeviceStatus_PrintMqttJson()`** 使用 **`%.1f`** 时，须在 Keil 中启用 **printf 浮点输出**（如 MicroLIB 相关选项），否则可能链接或运行异常。
- **`fputc`** 重定向在 **`System\usart\usart1.c`**（输出到 **USART1**）；串口助手波特率须与 **`uart1_Init`** 一致（默认 **57600**）。

## 3. 功能操作说明（单芯片工作流程）

### 3.1 总体流程

1. 上电后运行门禁、传感器轮询、WiFi、OLED、日志等；**OV7670+FIFO、SD、MQ-2** 均在 **同一 MCU**。
2. **显示**：`Task_OLED` 驱动 **PB8/PB9** OLED。
3. **MQ-2**：`Task_Sensor` 等通过 **`Driver\mq2.c`** 读 **PB0 ADC**（无从机上报路径）。
4. **抓拍**：入侵、密码锁定等调用 **`Capture_Request()`**；**`Task_Capture`**（`Capture.c`）完成 **本机** 采集并写 **SD** 为 BMP。
5. **门锁、蜂鸣器、燃气阀、MQTT、日志**：均在主机程内完成；**PIR 为 PC4**。
6. **设备状态 JSON**：`Task_SystemMonitor` 约 **每 2 秒**经 **USART1 `printf`** 输出（温湿度、MQ-2、门锁、布防、SD 等）；监听 **USART1、57600**。**OneNET 上云** 走 **USART3 + ESP8266**（软件侧 **`Uart2_Buf`**），与 USART1 JSON **通道与格式均不同**。

### 3.2 用户可感知操作

- **密码开锁**、**管理员模式**、**指纹**、**布防/撤防**、**日志查询（按键 9/7/8）**：操作方式与界面在 **本地 OLED** 上显示。
- **远程开锁**（串口/MQTT 等）：以 `main.c` / `esp8266_tls.c` 当前实现为准。
- **入侵报警**：**PIR PC4**；抓拍文件在 **本机 SD**；报警提示在 **本地 OLED/蜂鸣器** 等。

### 3.3 与已废止「双机方案」的差异（只读对照）

| 项目 | 旧双机（已移除） | 当前单芯片 |
|------|------------------|------------|
| 第二颗 MCU / USART3 交叉线 | 有 | **无** |
| 抓拍图像来源 | 从机经 USART 传图 | **本机 OV7670+FIFO** |
| MQ-2 | 常经协议从从机取 | **本机 PB0 ADC** |
| OLED | 曾描述主机 PA6/7 等 | **PB8/PB9**（以 `board_config` 为准） |

### 3.4 FreeRTOS 任务一览（`App_RTOS_Create`）

下列任务以 **`main.c`** 中 `xTaskCreate` 为准（优先级数字越大越优先抢占，与 FreeRTOS 配置一致）。

| 任务名 | 大致职责 |
|--------|----------|
| `Task_Security_Alarm` | 安防报警、MQ-2 紧急流程等 |
| `Task_Wifi_MQTT` | ESP8266：`ESP8266_TLS_Init()`、周期 **`OneNET_Parse_Cmd()`** 等 |
| `Task_Fingerprint` | AS608 指纹 |
| `Task_KeyScan` | 矩阵键盘 |
| `Task_Sensor` | DHT11、PIR、MQ-2 等 |
| `Task_Actuator` | 门锁、蜂鸣器、阀门等 |
| `Task_OLED` | OLED 刷新 |
| `Task_SystemMonitor` | 周期 **JSON**（USART1） |
| `Task_LinkageCmd` | 联动与串口指令解析等 |
| `Task_Capture` | 消费抓拍队列，**OV+FATFS 写 BMP** |

**`Capture_Task_Create()`** 在创建 `Task_Capture` 前调用，用于建立 **`g_cap_q`** 队列。

### 3.5 抓拍与图像数据流（本机）

- **入口**：业务调用 **`Capture_Request(CAP_EVT_...)`**（见 `capture_task.h` 中事件类型）。
- **执行**：默认 **`EN_OV7670_LOCAL=1`** 时，`Task_Capture` 执行 OV 采集并写 **`0:`** 盘 BMP（键盘 Y3/Y4 须 **PB1/PB2**）。`=0` 时任务占位不写盘，列线可用 **PA5/PA6**。
- **格式**：BMP **16-bit RGB565**（与 `Capture.c` 中头定义一致）。

## 4. 抓拍、SD 卡与状态上报

### 4.1 抓拍与 BMP

- **触发条件**：与 `Capture_Request` 调用处一致（如入侵、密码错误锁定等）。
- **路径**：FatFs 盘符 **`0:`**，文件名形如 **`CAP_<tick>_<idx>.BMP`**（以源码为准）。
- **格式**：RGB565 BMP（见 `Capture.c`）。
- **完成后上报**：`Capture_OnSaved` 等弱函数可配合 MQTT 上报文件名（若业务启用）。

### 4.2 SD 容量与挂载（`sd_capacity`）

- **初始化**：`App_RTOS_Init()` 中调用 **`SdCapacity_Init()`**。
- **占位实现**：可能不调用 `f_getfree`；**`sd.status` 长期 `unmounted`、容量为 0** 可为预期，不代表 SPI 一定失败。
- 需要真实容量时：在 `sd_capacity.c` 中启用 FatFs 统计逻辑后再看 JSON。

### 4.3 设备状态整包 JSON（周期约 2 s）

- **任务**：`Task_SystemMonitor`
- **接口**：**`DeviceStatus_PrintMqttJson()`**（`sd_capacity.c`），**USART1 `printf`**，行尾 **`\r\n`**
- **字段说明**：
  - `temp` / `humi`：DHT11（**PC5**）
  - `gas`：MQ-2 **ADC 整数值**（**PB0**）
  - `door`：门锁由 `gpio.h` 的 `RELAY` 定义（当前 **PB12**，低电平开锁 → **`"open"`**）；与 `board_config.h` 中 PC6 不一致时须二选一统一接线与代码
  - `arm`：布防 **1** / 撤防 **0**
  - `sd`：嵌套对象，同 §4.2

**示例**：

```text
{"temp":25.0,"humi":60.0,"gas":1200,"door":"closed","arm":1,"sd":{"status":"unmounted","total":0.0,"used":0.0,"usage":0}}
```

## 5. 历史日志、安全存储、TLS / WiFi

Flash **循环日志**（`syslog.c`）、**AES**（`secure_store.c`、`aes128.c`）。**ESP8266**：`esp8266_tls.c` 提供 **OneNET TCP + MQTT 3.1.1** 等；可选 **`esp8266_onenet_mqtt`**（AT+MQTT）由宏切换。

### 5.1 串口日志命令（USART1）

前缀 **`CMD:`**，例如：

- `CMD:LOG=LAST`
- `CMD:LOG=LAST,10`
- `CMD:LOG=TYPE=ALARM,5`

与 **指纹 / JSON** 共用 USART1 时，建议在非指纹操作时段发送。

### 5.2 ESP8266、OneNET 与可选 TLS

- **OneNET（`esp8266_tls.c`）**：在文件顶部配置 **`WIFI_SSID` / `WIFI_PASS`**、**`PROID` / `DEVID` / `ACCESS_KEY`**、**`MQTT_HOST` / `MQTT_PORT`** 等；使用 **2.4G WiFi**。鉴权方式以源码注释为准。
- **`Task_Wifi_MQTT`**：上电 **`ESP8266_TLS_Init()`**；若 **`ONENET_MQTT_ENABLE==1`** 可能走 **`ESP8266_OneNET_Mqtt_Connect()`**；否则走 **`ESP8266_TLS_Connect_MQTT()`**（SSL 路径与 OneNET 在线状态有关，见源码）。周期 **`OneNET_Parse_Cmd()`** 更新控制量。
- **属性上报**：业务中调用 **`OneNET_Publish_Data(...)`**；**USART1 JSON** 仍为本地调试通道。
- **缓冲**：**`Buf2_Max`**（`main.c`）建议 **≥512**，视 AT 应答长度调整。

## 6. 功能测试方法（单芯片）

### 6.1 基础接线核对

- **一块 MCU 板**上电，**各模块共地**；杜邦线建议按《硬件连接方案》**§2** 分模块成束，减少错脚。
- **OLED PB8/PB9**；键盘行 **PC0/PC1/PC2/PC3（X4）**，列 **Y1/Y2=PC11/PC12**，Y3/Y4：**默认 PB1/PB2**（开本地摄像头）；**SWD PA13/PA14**；门锁 **PC6**；蜂鸣器 **PC10**（`BEEP_SoundOn`/`Off`，极性见 `BOARD_BEEP_ACTIVE_HIGH`）；DHT11 **PC5**；PIR **PC4**；指纹 **USART1 + PA8(PS_Sta)**；**ESP8266 USART3 PB10/PB11，115200，EN→PC9**；燃气阀 **PC7**；照明 **PC8**；SD **PB12+PB13–15**；MQ-2 **PB0**；OV7670 按《硬件连接方案》（SCCB **PD2/PB7**，PB6 仅 OE）。**无通风/空调继电器。**

### 6.2 显示与传感器

- 上电后 **OLED** 菜单/状态正常；**DHT11** 变化反映到 JSON 的 `temp`/`humi`；**MQ-2** 反映到 `gas`。

### 6.3 全链路建议

- 布防 → 触发 **PIR** → 蜂鸣器/继电器/MQTT 按逻辑动作 → **SD 抓拍**（已接卡且 FatFs 正常时）。

### 6.4 SD 与 JSON

- **USART1** 监听 **57600** 查看 §4.3 JSON。
- 占位 `sd_capacity` 时 **`unmounted` 可为预期**。

### 6.5 建议最小验证顺序

1. **SWD 下载**与 **3.3V 供电**正常。  
2. **OLED（PB8/9）** 显示正常。  
3. **DHT11**：JSON 中温湿度变化。  
4. **SD**：能挂载并产生抓拍文件（视 FatFs 与接线）。  
5. **ESP8266**：网络与 OneNET（另接 USB-TTL 监听时只能**分时**占用 **USART1**，或仅观察模块串口；ESP 链路为 **USART3 PB10/11**，**115200**）。  
6. **指纹**：**PA9/10、PA8**；调试 JSON 时与指纹操作 **分时**。

## 7. 常见问题排查

### 7.1 通用

- **外设不工作**：核对 **`硬件\硬件连接方案.md`** 与 **`board_config.h`**。  
- **SD 不识别**：**PB12(CS)、PB13–PB15**、供电、SPI 模式；是否与 OV **同时** 错误占用 **PB14/PB15**。  
- **TLS/MQTT / OneNET**：WiFi 宏、**2.4G**、密钥、`Buf2_Max`、**USART3 / PB10·11** 接线、UART1 上 **`[OneNET]`** 日志。  

### 7.2 现象对照

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| OLED 无显示 | PB8/9 接反、地址、供电、共地 | 查 I2C 与 **3.3V** |
| `gas` 恒为 0 或异常 | MQ-2 未接 **PB0**、ADC 未初始化 | 查 `mq2.c` 与 `Task_Sensor` |
| ESP8266 无响应 | PB10/11 交叉错误、未共地、**115200**、供电、**EN(PC9)** | 查 `USART2_Init_Config`（实为 USART3）与模块电源 |
| 指纹无感应 | **PS_Sta 未接 PA8** | 对照模块手册 |
| 抓拍无文件 | OV 未接好、`EN_OV7670_LOCAL` 被改为 `0`、或初始化失败 | 默认应 **`1`**；查 SD/SPI2、OV 接线；键盘 Y3/Y4 须 **PB1/PB2** |
| JSON 乱码 | USART1 波特率非 **57600** | 与 `uart1_Init` 一致 |
| 已开摄像头仍无 BMP | SD 未接好、FatFs 未挂载、OV 初始化失败、任务栈/互斥 | 查 `Task_Capture`、`Capture.c`、SPI2；键盘 Y3/Y4 须为 **PB1/PB2** |
| 下载失败 | BOOT0、SWD 线序、**JTAG 未关导致 PA15 冲突** | 仅保留 SWD |

### 7.3 抓拍卡顿

抓拍与写 SD 在独立任务中；避免长时间关中断或高优先级任务饿死 `Task_Capture`。

### 7.4 SD 容量与 JSON

| 现象 | 处理 |
|------|------|
| `sd` 一直 `unmounted` | 多为占位实现；启用真实统计后复查 |
| `printf`/`%f` 链接错 | Keil 打开浮点 printf |

## 9. 安全与电气注意事项

- **燃气阀继电器**：仅作演示；真实燃气须合规施工。  
- **继电器与蜂鸣器**：注意驱动能力与反冲保护。  
- **电源**：ESP8266、SD 写卡、继电器动作电流大，稳压与退耦须充足。  
- **电平**：UART 为 **3.3V TTL**；5V 模块须电平转换。  
- **USB 与 PA12**：**PA12** 常与 USB D+ 复用；使用 USB 从机时勿再占用 **PA12** 作燃气阀。
